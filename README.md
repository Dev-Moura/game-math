# 🎮 Game Math

Um jogo de matemática desenvolvido em Python com o objetivo de praticar lógica de programação, Programação Orientada a Objetos (POO) e manipulação de entrada e saída no terminal.

O projeto apresenta desafios matemáticos ao usuário, permitindo exercitar operações básicas enquanto reforça conceitos de desenvolvimento de software.

---

## 🚀 Tecnologias Utilizadas

* Python 3.12
* Programação Orientada a Objetos (POO)
* PyProject
* Git e GitHub

---

## 📂 Estrutura do Projeto

```text
game-math/
│
├── game.py
├── test.py
├── pyproject.toml
│
├── models/
│   ├── calc.py
│   └── __init__.py
│
└── README.md
```

### Descrição dos Arquivos

| Arquivo          | Responsabilidade                                    |
| ---------------- | --------------------------------------------------- |
| `game.py`        | Arquivo principal responsável pela execução do jogo |
| `models/calc.py` | Contém a lógica das operações matemáticas           |
| `test.py`        | Arquivo utilizado para testes da aplicação          |
| `pyproject.toml` | Configuração do projeto Python                      |

---

## 🎯 Funcionalidades

* Geração de operações matemáticas
* Interação com o usuário pelo terminal
* Validação de respostas
* Sistema de pontuação
* Exercícios de raciocínio lógico

---

## ▶️ Como Executar

### Clone o repositório

```bash
git clone https://github.com/Dev-Moura/game-math.git
```

### Entre na pasta do projeto

```bash
cd game-math
```

### Execute o jogo

```bash
python game.py
```
